# Checklist producción

- [ ] Git/work tree sano y versión etiquetada.
- [ ] PHPUnit/Pest ejecutado y resultados registrados.
- [ ] SQL/migraciones reproducibles en MariaDB aislada.
- [ ] APP_DEBUG=false, secretos protegidos y HTTPS.
- [ ] RBAC/IDOR/CSRF/uploads/exports verificados.
- [ ] Inventario, dinero, pagos y estados consistentes.
- [ ] AJAX/API/Storage/correo/PDF/Excel probados.
- [ ] Assets, permisos, colas, scheduler y logs operativos.
- [ ] Backup/restauración/rollback probados.
- [ ] Aceptación académica y smoke tests documentados.
