# Análisis del sílabo y alcance académico

La solicitud del usuario identifica como objetivos de la Unidad III: comunicación AJAX/Fetch/JSON; API REST y seguridad de endpoints; Storage, correo y reportes PDF/Excel; carga de imágenes y generación de comprobantes; variables `.env`, rendimiento y despliegue en Hosting/VPS; informe final, exposición y práctica de despliegue.

Este diagnóstico no vuelve a abrir archivos fuera de `C:\xampp\htdocs\dwa2\sistema-cell-sac`, conforme a la instrucción expresa del usuario. Por ello los requisitos del sílabo se mantienen como requisitos proporcionados en la solicitud y deben cotejarse con el PDF cuando el usuario autorice esa ruta.

## Distinción

- Explícito: requisitos académicos anteriores.
- Derivado: demostración en vivo, informe, código fuente y resultados de laboratorio.
- Producción: HTTPS, secretos, backup/restauración, observabilidad y rollback.
- Opcional: mejoras empresariales no necesarias para la Unidad III.
