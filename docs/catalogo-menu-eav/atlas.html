Atlas técnico: menú lateral dinámico EAV

Capas

Blade layout → menu.js → GET /catalogo/menu → FormRequest → Controller → ServicioNavegacionCatalogo → ServicioCatalogo/EAV → JSON

Datos

categorias organiza la jerarquía; productos conserva datos comerciales; las cuatro tablas EAV existentes describen atributos, valores y asignaciones.

Interacción

El panel usa una pila de respuestas, solicitudes cancelables con AbortController, estados de carga/error/vacío y una transición lateral respetuosa con reducción de movimiento.

Endpoint

GET /catalogo/menu devuelve título, nivel, contexto, opciones, conteos y enlaces de productos compatibles.

Integridad

La migración agrega categoria_padre_id y orden de forma incremental. No elimina registros ni ejecuta cambios sobre la base principal.
